# Application Python de gestion des tâches

## Description
Cette application en console permet d'ajouter, d'afficher et de rechercher des tâches quotidiennes.

## Fonctionnalités
- Ajouter une tâche avec un titre non vide.
- Afficher toutes les tâches avec leur numéro.
- Rechercher les tâches à partir d'un mot-clé.
- Quitter le programme avec le choix `0`.
- Afficher un message si la liste est vide ou si aucune tâche ne correspond à la recherche.

## Fichiers
- `main.py` : code de l'application.
- `README.md` : présentation et instructions du projet.

## Exécution avec Visual Studio Code
1. Ouvrir le dossier du projet dans Visual Studio Code.
2. Ouvrir le fichier `main.py`.
3. Cliquer sur le bouton **Run Python File** en haut à droite.
4. Utiliser le menu dans le terminal.
